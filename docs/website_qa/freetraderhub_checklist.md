# FreeTraderHub QA Checklist

Use this before recommending publication or production deployment.

## Calculator and Tool Behavior

- [ ] All calculators work.
- [ ] Inputs validate correctly.
- [ ] Empty, zero, extreme, and malformed inputs do not break the page.
- [ ] Results update clearly after input changes.
- [ ] Formula or result explanation is visible and understandable.
- [ ] Buttons provide feedback.

## Navigation and Layout

- [ ] Mobile layout works.
- [ ] Desktop layout works.
- [ ] Navigation works.
- [ ] No broken internal links.
- [ ] No broken external links.
- [ ] The user can understand the page purpose in under 10 seconds.

## Content Quality

- [ ] Tool purpose is clear.
- [ ] Copy is specific to prop-firm traders and trading tools.
- [ ] No generic AI filler copy.
- [ ] No unnecessary animations.
- [ ] Risk language is clear and does not imply guaranteed trading outcomes.

## SEO and Performance

- [ ] SEO title exists.
- [ ] Meta description exists.
- [ ] Page loads quickly.
- [ ] Main content is visible without confusing delays.

## Approval Gate

- [ ] Any publishing or deployment recommendation has an approval request.
- [ ] Approval status is `PENDING_CEO_APPROVAL` until the CEO approves.
